# life-path-explorer

个人优势与人生路径探索 Skill。从具体经历形成可纠正的优势假设，比较不同未来，设计小实验，并根据真实反馈接着复盘。

## 三个入口

| 当前需求 | Skill会做什么 |
| --- | --- |
| 不知道往哪里走 | 梳理问题与经历，探索三种五年未来并比较 |
| 已经有方向，想确认能否推进 | 检查关键未知，直接给首轮实验卡 |
| 带着尝试结果回来 | 对照原假设与标准复盘，更新下一步 |

实际对话按信息缺口提问，不要求回答固定数量的问题。优势是附有依据和限制的假设；收入分析按需求展开，不编造五年收益。

## 安装

安装到当前项目的 Codex：

```bash
npx skills add wu13628310487-bit/life-path-explorer --skill life-path-explorer --agent codex --yes
```

本地仓库试装时，可以将来源替换为 `.`。省略全局安装参数，默认在当前项目安装。

也可以把 `skills/life-path-explorer/` 放到所用 Agent 支持的 Skill 目录。格式和发现行为以目标宿主为准。

若 npm 提示旧缓存无写权限，可给 `npx` 加 `--cache ./.skills-npm-cache` 使用当前目录下的独立缓存，无需修改原缓存权限。

## 最短使用示例

```text
请用 $life-path-explorer 帮我探索下一步方向。
我会提供当前问题、相关经历和不能牺牲的条件。
先复用已有信息，只问影响判断的缺口。
```

```text
请用 $life-path-explorer 验证我已经选定的方向。
直接帮我找关键假设，并设计本周能得到反馈的小实验。
```

```text
请用 $life-path-explorer 复盘下面的实验记录。
区分实际结果、未确认事项和需要修改的判断。
```

## 交付

- 完整探索：当前问题、经历依据、优势假设、三条路线、比较及首轮实验。
- 局部验证：一张包含行动、投入上限、材料和观察标准的实验卡。
- 反馈复盘：原判断、新证据、具体修订及下次入口。
- 暂停：已知、假设、未解问题与接续点。

输出为便于复制到飞书等文档的文字和必要表格。没有外部API或服务依赖；实际表现取决于执行的模型与宿主工具。

Skill不会单独提供自动存档、跨会话记忆或提醒。记录需要实际保存和读回；只有用户要求且工具可用时才执行写入。

一处非关键简化：退休生活样本每条路线只展开一个关键问题，未完整列出原版三个探索问题。使用完整练习时应检查这一项。

额外的独立 Codex CLI 端到端试跑已读取 Skill，但超时未生成最终回答，未计为通过。没有量化验证自动触发率，也没有验证其他宿主。

以上只覆盖包、安装与构造场景行为，不证明真实用户的人生或收入结果。
