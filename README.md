# 人生路径探索 · life-path-explorer

**作者：奕文Even · 版本：0.1.0 · MIT**

一个帮助你梳理优势、比较人生与职业方向、设计小实验并持续复盘的 AI Skill。它从你的真实经历出发，把“想清楚”推进到“做一次，再看反馈”。

## 什么时候用

| 你现在的情况 | 从哪里开始 | 这次会得到什么 |
| --- | --- | --- |
| 想法很多，不知道往哪里走 | 探索方向 | 经历依据、优势假设、三种五年未来与比较 |
| 已经选好方向，想试一试 | 验证方向 | 一张有动作、投入上限和观察标准的实验卡 |
| 做过一些尝试，想知道下一步 | 反馈复盘 | 实际结果、判断修订和一个优先下一步 |

不要求你先做测评、准备完整履历或回答固定的 100 道题。已有方向时可以直接设计实验。

## 三步开始

### 1. 安装到项目

准备好可使用的 Codex，以及 Node.js / npm。在你要使用这个 Skill 的项目文件夹打开终端，运行：

```bash
npx --yes skills add yiwen-even/life-path-explorer --skill life-path-explorer --agent codex --yes
```

本项目实际验证的是 Codex 的项目级安装，安装目录为 `.agents/skills/life-path-explorer/`。其他宿主的识别与执行效果尚未验证。

遇到 GitHub 下载中断时，[使用指南](USAGE.md)提供了已验证的官方压缩包安装方式。

### 2. 在 Codex 中发送

```text
请用 $life-path-explorer 帮我探索下一步方向。
我目前最困惑的是：【写一句你正在卡住的事】
先复用我已经提供的相关信息，一次只问一个影响判断的问题。
```

已经有方向，直接说：

```text
请用 $life-path-explorer 验证我已经选定的方向。
我的方向是：【填写】
这周最多能投入：【时间与费用上限】
请直接找一个最关键的未知，设计一次能获得真实反馈的小实验。
```

### 3. 实际尝试后回来复盘

```text
请用 $life-path-explorer 复盘这次实验。
原实验卡：【粘贴】
我实际做了什么、得到什么反馈：【填写】
请区分已完成、部分完成和未确认，说明哪些判断需要修改，
再给我一个优先下一步。
```

完整填写示例、暂停与续接、安装排查，见 **[使用指南](USAGE.md)**。

## 它怎么工作

```text
明确当前问题
  → 找具体经历与依据
  → 形成可纠正的优势假设
  → 探索并比较不同未来
  → 选一个关键未知，做小实验
  → 根据真实反馈修订
```

完整探索保留奥德赛计划的三种五年未来：延续当前、当前方向不能继续时的另一条路、暂时放下金钱与评价限制的生活。比较资源、喜欢程度、信心和一致性，由你表达取舍。

验证与复盘可以跳过完整三路线练习。输出用可复制的文字和必要表格，可以整理到飞书、Obsidian 或自己的文档。

## 使用边界

- 优势是有依据、有适用条件的假设，允许你纠正，不是人格或天赋定论。
- 计划、愿望、AI 建议、本人决定和实际结果分别记录。
- 收入只在相关时分析，说明条件与缺口，不编造五年收入曲线。
- Skill 没有独立后台，也不会自动记住其他聊天、保存文件或设置提醒。需要接续时带上上次记录；写入必须由宿主实际完成并读回。
- Skill 本身不调用外部 API。对话数据由你所用的模型与宿主处理。

## 验证与维护

| 项目 | 当前证据 |
| --- | --- |
| 包结构、引用、接口、可携带性和来源 | 6 项检查通过 |
| 结构回归 | CRLF 正常包通过；缺参考、私人路径和许可证不一致被正确拒绝 |
| 构造行为场景 | 12 题按预写标准通过，无关键失败 |
| 实际安装包执行 | 另 1 个构造案例完成，保留 90 分钟上限与未确认人选 |
| 本地与 GitHub 隔离安装 | 仓库源与官方压缩包均已安装核对，6 个 Skill 资源与源码逐文件一致 |

场景由未读实现的测试设计者准备，三位执行者各处理四题，没有读取判分标准；判分由实现者完成，不属于独立盲评，组内共享上下文。一个退休生活样本每条路线只列一个探索问题，完整练习应检查原版三个问题是否齐全。

额外的独立 Codex CLI 完整试跑曾超时，没有最终回答，未计为通过。未量化自动触发率，也未验证真实用户的长期人生或收入结果。安装器的已测版本为 `skills` 1.9.0。

下载源码后，可运行包校验：

```bash
node tools/validate.mjs
```
