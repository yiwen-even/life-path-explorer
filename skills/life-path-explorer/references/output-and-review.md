# 输出、实验与复盘模板

仅在需要相应交付时读取和使用。模板字段用于保留信息，不要求用户补齐所有字段后才获得帮助。

## 完整探索记录

```text
当前问题与阶段：
本次希望获得的进展：
相关约束及来源：

本人陈述与材料：
愿望：
优势假设、依据与反例：
未确认或冲突：

路线A：延续当前
路线B：当前方向不可继续时的其他可能
路线C：暂时放下金钱和评价后的生活
各路线：日常生活、主要活动、五年草图、资源、吸引力、
代价、三个探索问题。

比较：资源、喜欢程度、信心、一致性；评价者、理由和未知。
本轮优先验证的未知：
当前实验：
实际反馈：
本人已明确的决定：
下次入口：
来源日期／整理日期：
```

局部任务只输出相关部分，注明没有展开完整探索。用户尚未评分、选择、执行或反馈的项目，标为未确认。

## 实验卡

```text
要弄清的问题：
当前假设及依据：
本次只验证什么：
具体动作：
相关对象或使用情境：
时间与其他投入上限：
交付物和观察材料：
开始前约定的观察标准：
复盘时间或事件条件：
缩小、暂停或停止的条件：
尚待用户选择的参数：
```

优先安排一个能减少关键未知的动作。约一周只是首轮建议；用户给定时间或任务性质优先。

当用户提供了可用时间，检查所有步骤的时间合计不超限。关键投入未知时，询问或标待确认；不要用未经用户确认的示例数值登记承诺。

访谈能提供对方经验；作品试用能提供制作或使用信号；是否喜欢长期做、是否需要、是否愿付费需分别观察。

验收标准在开始前记录。材料不支持结论时保留证据不足，不能为了给出方向强行二选一。

## 虚构示例：教程可用性实验

假设：没有本人现场指导时，新手可以依据教程完成一个指定任务。

行动：在用户确认投入和对象后，制作最小教程并请有相关需求、同意试用的人尝试。

观察：完成情况、卡点、额外指导次数及使用者反馈。开始前约定人数与成功标准，数值由实际目标确定。

结果只支持相应的可用性或解释能力判断，不能直接证明存在付费需求。

## 复盘

1. 读回原问题、假设、标准和投入上限；材料不可访问就说明缺口。
2. 记录实际状态：已完成、部分完成、明确未做、阻塞、取消、未确认。
3. 区分完成写作、提交、试用、认可、邀请与实际收款。
4. 结果分类：支持、反驳、证据不足，标明影响哪项判断。
5. 保留旧判断、新材料、修订原因与时间。
6. 给一个优先下一步；已有本人选择时沿用，其他建议不当作已批准。

未勾选、未回复、时间已经过去，都不能单独证明失败。

差结果不自动否定个人能力；好结果也不自动证明可扩大。对照原标准与条件再作建议。

用户明确取消时停止迁移任务，不擅自建立新计划或提醒。

## 暂停与接续

只保留已知、当前假设、未解问题、当前阶段和下次入口。不要趁暂停继续列问题或安排新任务。

用户要求写入且目标清楚、工具可用时，遵循宿主规则更新用户指定记录并读回。已有正文应保留，实验历史增量更新。

没有执行写入就提供可复制正文。后续对话需要实际可读记录；不能仅靠 Skill 文件宣称具备自动记忆、同步或通知能力。
